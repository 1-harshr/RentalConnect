# Tenant-Owner Management System
## Product Proposal

### Executive Summary
A mobile application that streamlines the relationship between property owners and tenants by enabling owners to manage their properties and tenant assignments, while giving tenants visibility into their rental properties and owner information. The system creates a centralized hub for property management with a roadmap to include a complaint resolution system.

---

### Core Vision
Simplify property management by providing owners with tools to manage their portfolio and tenants with transparency and direct owner access — laying the foundation for a complaint and maintenance request system.

---

### Phase 1: Core MVP Features

#### **Owner Features**
- **Property Management**
    - Register and list multiple properties (address, HNO, photos, availability status, map location)
    - View all registered properties
    - View all tenants assigned to each property

- **Tenant Management**
    - Add tenants to properties
    - Remove tenants from properties
    - View tenant details (name, hometown, phone, Aadhar ID)

#### **Tenant Features**
- **Property Discovery**
    - View assigned properties with full details
    - Access property information (address, photos, maps, availability)

- **Owner Connection**
    - View owner profile and contact information
    - Direct visibility into owner details

#### **Account & Registration**
- Role-based registration (Owner or Tenant)
- Profile management for both roles
- Secure authentication

---

### Phase 2: Complaints & Maintenance System (Future)
- Tenants can file complaints/maintenance requests against properties
- Owners can review and respond to complaints
- Ticket tracking and resolution workflow
- Communication history between tenant and owner

---

### User Personas

**Owner**
- Manages 1+ rental properties
- Needs efficient tenant assignment and tracking
- Wants visibility into property status and tenant interactions

**Tenant**
- Rents from one or more owners
- Needs to see property details and owner information
- Will report maintenance issues and complaints

---

### Key Benefits
- **For Owners**: Centralized property and tenant management without external tools
- **For Tenants**: Clear visibility and direct channel to property/owner information
- **For Both**: Foundation for structured communication and issue resolution

---

### Success Metrics
- Owner adoption: # of properties registered
- Tenant engagement: # of properties viewed, owner profile visits
- System readiness for Phase 2: baseline complaint volume estimation

---
